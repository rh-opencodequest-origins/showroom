Platform Engineer Activity: Correct a template

Create a new software Component and supporting infrastructure using the OpenCodeQuest - Quarkus CRUD microservice template that was created by the platform engineer.

This template has been generated by an AI. Use it carefully ;)

Explore the Template

✍️ Time to practise ✍️

  1. Access Red Hat Developer Hub.

  2. Click the Create icon (plus symbol) in the top menu.

  3. Click the Choose button on the OpenCodeQuest - Quarkus CRUD microservice. The Template parameters collection screen will be displayed.

  4. Oups! This is a template generated by an amazing over-trained AI model.. Hopefully, you are smart enough to correct the work done by the dummy AI!

  5. In Step 1, "Prompt me something". Yes, it’s not relevant at all

    • OpenShift version is not useful to onboard a developer. You should modify the template

Update the Template with a human touch!

  1. Click the Create icon (plus symbol) in the top menu.

  2. Click the Choose button on the OpenCodeQuest - Quarkus CRUD microservice. The Template parameters collection screen will be displayed.

  3. Click on the 3 dots button as shown in the picture.

    Remember, Templates imported previously are located in GitLab. We will directly edit it and commit it!

Update the title of the input form

  1. Find the YAML surrounded by update the title below and replace the title.

    *Prompt me something* by *OpenShift Cluster URL*

  2. Scroll down and enter a commit message feat: change application title.

  3. Click the Commit changes button.

Refresh the template updated

Templates are refreshed asynchronously by Developer Hub. We will see how to refresh it manually.

Let’s find the template to refresh!

  1. Step 1 - Click on Catalog

  2. Step 2 - Select Template type

  3. Step 3 - Click on the template OpenCodeQuest - Quarkus CRUD microservice : - the name could be different from the screenshot

Refresh it!
