== What you've learned

Throughout this workshop, you have experienced the full lifecycle of Platform Engineering with {product_name_rhdh}:

* How to design and deploy an Internal Developer Platform using {product_name_rhdh}
* How to integrate authentication (Keycloak), source code management (GitLab), and GitOps (Argo CD)
* How to create and use software templates to standardize application onboarding
* How to deploy microservices from the inner loop to production using golden paths
* How to secure application deployments with policy-driven pipelines

== Ready to improve your developer experience?

Now you know what Platform Engineering brings to your development project:

* Consistency between tools
* End-to-end process to onboard developers
* Control and monitoring of how developer tools are consumed

Think about an open way to collaborate for your existing and next development project:
